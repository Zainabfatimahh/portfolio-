# Xainab Fatimah — Portfolio

A responsive portfolio website for:
- Graphic Design
- UI/UX Design
- Full-Stack Web Development
- Mobile App Development

## Included
- Responsive modern dark portfolio
- Animated reveal effects
- Project category filters
- Web, mobile and desktop projects
- Behance preview modal with full-profile fallback
- Fiverr testimonials
- Certifications
- Experience timeline
- Social profile icons
- Contact CTA
- Mobile navigation

## Run
Open `index.html` in a browser.

## Customize
Edit project links/text in `index.html`.
Edit colors/layout in `style.css`.
Edit interactions in `script.js`.

Note: The Behance "quick preview" is intentionally a portfolio preview card rather than a live embedded Behance page because Behance may block iframe embedding in some browsers. The modal includes a direct "Open full Behance portfolio" button.
